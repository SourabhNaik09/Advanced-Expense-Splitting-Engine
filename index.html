How the Graph Algorithm Works

1.Graph Representation: Each person is a node, and each debt is a directed edge with a weight (amount).
2.Balance Calculation: Calculate net balance for each node (total owed − total owing).
3.Greedy Simplification: Repeatedly match the largest creditor with the largest debtor, settling as much as possible in one transaction.
4.Result: The minimum number of edges (transactions) needed to zero out all balances — provably optimal at O(n log n).
